# 部署说明

两种使用方式:**桌面版应用**(最终用户,免装 Python,推荐,见 [桌面版打包说明.md](桌面版打包说明.md))与**手动部署**(开发者 / 服务器,本文件)。

## 一、环境要求(手动部署)

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10/11(64 位)或 macOS / Linux |
| Python | 3.9 ~ 3.12(64 位),安装时勾选 "Add Python to PATH"(Windows) |
| 网络 | 首次需联网安装依赖(约 1~3 分钟,已配置国内镜像);DEM 瓦片缺失时分析阶段也会自动联网补齐 |
| 磁盘 | 依赖约 200 MB;`data/dem` 会随使用增长(全国全量约 15~25 GB) |

## 二、手动部署

1. 把整个项目文件夹复制到目标电脑(建议路径不含空格和中文)
2. 在项目根目录执行:

```bash
python -m venv .venv
# Windows 把 .venv/bin 换成 .venv\Scripts
.venv/bin/pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 启动(--app-dir 指向 src,任意位置可用)
.venv/bin/uvicorn --app-dir src server:app --host 127.0.0.1 --port 8107
```

3. 浏览器打开 `http://127.0.0.1:8107`

## 三、从当前电脑打包迁移

在 macOS 上打包(排除虚拟环境等不可跨平台内容):

```bash
cd ~/开发项目新
zip -r 高程计算.zip 高程计算 \
  -x "高程计算/.venv/*" "*__pycache__*" "*.pyc" \
     "高程计算/data/dem/*.part*" "高程计算/dist/*" "高程计算/build/*"
```

说明:

- **`data/dem` 建议一起打包**:目标电脑离线也能直接分析已覆盖区域;若想减小体积,可在上面的命令再加 `-x "高程计算/data/dem/*"`,目标电脑首次分析时会自动下载所需瓦片
- `.venv` 是本机编译的虚拟环境,**不可跨平台**,必须排除,目标机器按上面第二步重建
- `data/boundaries`(行政边界缓存,几百 KB)建议保留

## 四、日常使用

- 服务地址:`http://127.0.0.1:8107`(仅本机访问)
- 局域网访问:把启动命令中 `--host 127.0.0.1` 改为 `--host 0.0.0.0`,并在防火墙放行该端口;访问地址换成 `http://本机IP:8107`
- 修改端口:改启动命令里的 `--port`(8107 被占用时换 8200 等)
- DEM 自动下载默认开启(`AUTO_DOWNLOAD=0` 可关闭);断网时只可分析本地已有瓦片区域

## 五、目录结构(哪些需要备份/迁移)

```
高程计算/
├── src/                      # 全部 Python 代码(server.py / desktop.py / download_dem.py)
├── static/                   # 网页界面(含本地化 Leaflet,离线可用)
├── assets/                   # 桌面版应用图标
├── doc/                      # 文档(本目录)
├── requirements.txt          # Python 依赖清单
├── data/
│   ├── dem/                  # DEM 瓦片(核心数据,建议一起迁移)
│   └── boundaries/           # 行政边界缓存
└── .venv/                    # 虚拟环境(不迁移,自动重建)
```

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 依赖安装很慢/失败 | 脚本已用清华镜像;仍失败可检查代理,或手动执行 `.venv/bin/pip install -r requirements.txt` |
| 端口被占用 | 启动命令换 `--port`(如 8200) |
| 首次分析某个新区域很慢 | 正在自动下载该区域 DEM 瓦片(每片 20~50 MB),下完后同区域秒级 |
| 分析报"轨迹覆盖 N 个缺失瓦片" | 自动下载被关闭或断网;联网重试,或运行 `python src/download_dem.py` 预先下载 |
| 上传后高程全为空 | 轨迹超出数据覆盖范围(仅支持经度 73~136°、纬度 17~54°) |

## 七、升级

只需把新版 `src/`、`static/`、`requirements.txt` 覆盖到旧目录即可,`data/` 数据不受影响;若 `requirements.txt` 有变化,删掉 `.venv` 文件夹后重新安装依赖。桌面版改代码后须重新打包才会带上新改动。
